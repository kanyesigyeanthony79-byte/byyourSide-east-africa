# ByYourSide East Africa Website

GitHub Pages-ready MVP website.

## Files
- `index.html` — main website
- `styles.css` — website design
- `script.js` — Request a Companion form

## Request flow
The form currently sends the request to the ByYourSide WhatsApp number:
+256 787 612 459

## Publishing
Upload all three files to the root of the GitHub repository, then enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → / (root).
